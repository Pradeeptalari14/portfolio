Database Outage / Connection Exhaustion

            
HTTP 500 / 503 errors spike. PostgreSQL logs: "FATAL: remaining connection slots are reserved".

          

          

            
              CRITICAL - OUTAGE DETECTED
            
            
          

        


        

          

            
Root Cause Investigation

            

              Backend microservices opening unpooled direct connections per request without limits, exceeding PostgreSQL max_connections setting.
            


            
SRE Telemetry Live Stream

            
[FATAL] pq: remaining connection slots are reserved for non-replication superuser connections
[ERROR] sqlalchemy.exc.OperationalError: server closed the connection unexpectedly
[ALERT] Prometheus Rule 'PostgresHighConnections' firing (99.2% utilization)
[TRACE] HTTP 503 Service Unavailable returned to 4,210 concurrent users

          


          

            
Engineering Remediation & Runbook

            
1. Introduce PgBouncer connection pooler in Transaction Pooling mode.
2. Configure pool_size = ((2 * CPU_CORES) + EFFECTIVE_SPINDLES).
3. Set statement_timeout = 2500ms to terminate rogue queries.
4. Route read-only queries to asynchronous Read Replicas.

Beginner: The Busy Restaurant Analogy

            

              Think of the backend ecosystem as a high-end restaurant:
              


              • Client (Customer): Sits at the table and places an order.

              • Ingress / Waiter (API Gateway): Greets the customer, checks if they have a reservation (Auth), and writes down the ticket.

              • Pantry Shelf (Redis Cache): Ready-made appetizers grabbed immediately without cooking (sub-2ms).

              • Chef & Kitchen (Backend API): Prepares custom dishes according to business rules.

              • Deep Storage / Fridge (Database): High-capacity, durable ingredient storage where everything is cataloged.

              • Delivery Driver (Queue & Async Worker): Takes cooked meals and delivers them across town without forcing the waiter to leave the restaurant.
