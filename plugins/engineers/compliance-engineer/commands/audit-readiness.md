# /compliance-engineer:audit-readiness

Assess audit readiness and list evidence gaps for a framework.

## Usage

```
/compliance-engineer:audit-readiness $ARGUMENTS
```

## Steps

1. List the requirements in scope.
2. Match existing controls and evidence.
3. Flag missing or stale evidence.
4. Create a remediation timeline.

## Output

A readiness score by area, evidence gaps and a remediation plan.

If the input is missing or ambiguous, ask one focused question before continuing.
