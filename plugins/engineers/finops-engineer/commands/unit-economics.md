# /finops-engineer:unit-economics

Define unit cost metrics for a product or service.

## Usage

```
/finops-engineer:unit-economics $ARGUMENTS
```

## Steps

1. Choose the unit that reflects customer value.
2. Map direct and shared costs to the unit.
3. Compute the current unit cost and its trend.
4. Set a target and the levers to reach it.

## Output

A unit-cost model with assumptions, current value and improvement levers.

If the input is missing or ambiguous, ask one focused question before continuing.
