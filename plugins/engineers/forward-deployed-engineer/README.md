# 🚀 Forward Deployed AI Engineer

Bridging client discovery, agentic AI architecture, air-gapped private VPC deployments, and continuous acceptance evals.

**Group:** Operations & Delivery  
**Typical tools:** LangGraph, Model Context Protocol (MCP), Kubernetes Helm, vLLM, Presidio, Ragas, DeepEval

## Real-World Production Scenario & Impact

- **Production Scenario:** Enterprise Clinical Decision System: Embedding with hospital IT and CISO to frame clinical document search, deploying containerized MCP agent swarms into zero-egress private VPC, and attesting 96.4% faithfulness via Ragas golden sets.
- **Measurable Business Gain:** Shrinks client deployment cycle from 6 months to 14 days and guarantees zero data leakage outside customer perimeter.
