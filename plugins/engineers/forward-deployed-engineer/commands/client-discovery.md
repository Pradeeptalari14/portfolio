# /forward-deployed-engineer:client-discovery

Produce a structured client problem statement, value stream map and acceptance SLA.

## Usage

```
/forward-deployed-engineer:client-discovery $ARGUMENTS
```

## Steps

1. Diagnose operational bottlenecks and calculate human labor cost.
2. Structure a 100-scenario golden evaluation benchmark.
3. Draft the 5-phase delivery timeline and acceptance gates.

## Output

A comprehensive FDE client discovery brief and SOW milestone matrix.

If the input is missing or ambiguous, ask one focused question before continuing.
