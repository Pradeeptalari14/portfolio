# ✅ QA and Test Automation Engineer

Test strategy, automation pyramid, flaky test control and contract testing.

**Group:** Security, Quality & Application  
**Typical tools:** Playwright, Vitest, Pytest, Pact, k6

## Real-World Production Scenario & Impact

- **Production Scenario:** Flaky Test Elimination: Profiles 2,000 integration tests in CI matrix; replaces arbitrary sleep calls with deterministic WebSocket event listeners.
- **Measurable Business Gain:** Reduces CI test failure rate from 14% to 0.1%; cuts pipeline runtime from 28 minutes to 9 minutes.
