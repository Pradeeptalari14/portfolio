What is Kubernetes?

Kubernetes is an open-source container orchestration platform designed to automate deploying, scaling, and managing containerized applications across cloud clusters.

Learning Objectives
  • ✓ Understand Kubernetes control plane and worker node responsibilities.
  • ✓ Learn how Deployments maintain desired state through declarative manifests.
  • ✓ Know when to use ClusterIP, NodePort, and LoadBalancer Services.
Key Production Benefits
✅ Automated Deployment: Seamless rolling updates with zero downtime.
✅ Self-Healing: Restarts crashed containers and reschedules failed nodes.
✅ Auto-Scaling: Dynamic horizontal pod autoscaling based on CPU/RAM/metrics.
✅ Portability: Runs identically on AWS, Azure, GCP, or bare-metal on-premise.

Lab: Deploy a Web Application on Kubernetes

Deploy a containerized web application using Kubernetes Deployments and Services

⏱️ ~30 min • Intermediate

2. Deploy Application

Deploy the containerized web application using a Kubernetes Deployment manifest with 3 replicas and rolling update strategy.

Expected Output
$ kubectl get deployments
NAME      READY   UP-TO-DATE   AVAILABLE   AGE
web-app   3/3     3            3           18s
💡 Need Help? Check Hints & Solution
Make sure your matchLabels match the template labels exactly (app: web-app).
Click Quick Command 'kubectl get pods' or execute 'kubectl apply -f deployment.yaml'.
apiVersion: apps/v1
kind: Deployment
metadata:
  name: web-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: web-app
  template:
    metadata:
      labels:
        app: web-app
    spec:
      containers:
      - name: web
        image: nginx:1.25-alpine
